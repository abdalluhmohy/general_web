# ذهب النيل للأعمال المتكاملة المحدودة
# Zaheb Alnile for Integrated Services Ltd.

نظام ويب داخلي لشركة سودانية متخصصة في فحص الذهب والمعادن، البيع والشراء، وتقنيات الذكاء الاصطناعي في التعدين.

---

## 🎯 نظرة عامة

- **نوع المشروع:** نظام داخلي مغلق (5 مستخدمين: مالك + 4 شركاء بصلاحية قراءة).
- **الواجهة الأمامية:** HTML / CSS / Vanilla JavaScript (بدون build tools).
- **الخلفية:** Supabase (Auth + PostgreSQL + RLS).
- **الاستضافة:** Render (Python static server).
